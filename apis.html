African Union (AU) Data

Research was conducted to find a suitable public data API from the African Union. The available data portals, such as the Pan-African Parliament's open data portal, focus on legislative and administrative documents rather than statistical data relevant to this project's themes. The ECAStats portal, while promising, does not yet have a publicly accessible REST API. Therefore, direct integration of AU data is not currently feasible.

United Nations Development Programme (UNDP) Data

An extensive search for a UNDP public data API was performed. While an API was discovered at open.undp.org, it appears to be outdated or discontinued, as attempts to access it resulted in errors. Without a functional and documented public API, a live data integration for UNDP could not be implemented.

Microsoft Azure Data

The Microsoft Azure platform offers a service called Azure Open Datasets. However, this service is designed for use within the Azure cloud environment for machine learning and data analytics, and does not provide a direct, queryable web API suitable for integration into this website. Therefore, a live data feed from Azure Open Datasets could not be established.
