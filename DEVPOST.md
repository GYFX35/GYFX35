# Global Peace, Youth Entrepreneurship, and Wellbeing Platform

## The Problem

In today's interconnected world, global challenges like conflict, youth unemployment, and declining wellbeing are more pressing than ever. Young people, in particular, face significant barriers to achieving their full potential. They often lack access to the resources, networks, and opportunities needed to create positive change in their communities and the world.

## The Solution

The Global Peace, Youth Entrepreneurship, and Wellbeing Platform is a comprehensive web-based solution designed to address these challenges. Our platform empowers individuals and organizations to collaborate, innovate, and build a better future by providing a centralized hub for:

*   **Global Peace and Stability:** Fostering dialogue, understanding, and collaboration to build a more peaceful world.
*   **Youth Entrepreneurship and Employment:** Empowering the next generation of leaders and innovators with resources, mentorship, and opportunities.
*   **Wellbeing Promotion:** Cultivating physical, mental, and social wellbeing for all through access to information, support networks, and expert guidance.

## Features

Our platform offers a wide range of features designed to support our three core pillars:

*   **AI-Powered Assistant:** A sophisticated AI assistant, powered by Google's Gemini Pro, provides expert guidance on a wide range of topics, including medicine, education, generative AI, consulting, marketing, software engineering, and more.
*   **Data-Driven Insights:** We leverage APIs from organizations like the World Bank, WHO, and UNESCO to provide users with up-to-date data and insights on global trends in economics, health, and education.
*   **Interactive Forums:** A space for users to connect, share ideas, and collaborate on projects related to peace, entrepreneurship, and wellbeing.
*   **Resource Hub:** A curated collection of articles, videos, and other resources to support users in their personal and professional development.
*   **Project Showcase:** A platform for users to showcase their projects and initiatives, and to connect with potential collaborators and funders.
*   **Global Connectivity:** We provide access to information on global banks, governments, universities, and mobile operators to help users connect with opportunities around the world.
*   **Media Sharing:** Users can upload and share photos and videos to document their work and inspire others.

## Technologies Used

Our platform is built on a modern, serverless architecture that is scalable, reliable, and secure.

*   **Frontend:** HTML5, CSS3, JavaScript (ES6)
*   **Backend:** Cloudflare Workers, Cloudflare D1 (database), Cloudflare R2 (storage)
*   **APIs:**
    *   Google AI Platform (Gemini Pro)
    *   Google Custom Search
    *   YouTube Data API
    *   World Bank Open Data API
    *   World Health Organization (WHO) API
    *   UNESCO Institute for Statistics (UIS) API
    *   Global Biodiversity Information Facility (GBIF) API
    *   Cisco Webex and Meraki APIs

## How to Run the Project

To run the project locally, you will need to have Node.js and npm installed.

1.  Clone the repository:
    ```bash
    git clone https://github.com/GYFX35/GYFX35.git
    ```
2.  Install the dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm start
    ```
4.  Open your browser and navigate to `http://localhost:8788`.
